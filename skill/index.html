यह क्या है / what this is

A skill folder that any Claude (Claude Code, Claude desktop, claude.ai with Skills) can load. Once loaded, ask in Hindi or English — कितने स्थान किस वर्ग को? महिला स्थान odd में ऊपर या नीचे? 50% से ऊपर हो गया तो किसे घटाएँ? नियम 7(13) क्या बाहर करता है? कार्यवाही विवरण में क्या लिखें? — and it answers verdict → clause (verbatim) → what the state did in 2026 → what to record / who must decide. Includes a calculator (scripts/quota.py) that reproduces the Dausa 2026 numbers.

Install

  1. Download the zip and unzip it.
  2. Claude Code / Claude desktop: move the folder to ~/.claude/skills/rajasthan-reservation-lottery-desk/, start a new session, ask your question (or type /rajasthan-reservation-lottery-desk).
  3. claude.ai with Skills: Settings → Skills → add the folder/zip.
  4. No Claude? The FAQ and court quotes read on their own.
