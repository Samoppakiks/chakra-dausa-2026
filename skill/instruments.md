# Instruments — the FULL names, numbers, dates and issuers behind every shorthand used in this skill

**Rule for answers (binding, from SKILL.md):** the first time an instrument is mentioned in any answer, letter or proceedings text, write it in FULL as in the "Full citation" column (Hindi form for spoken/Hindi answers). Shorthand ("Circular 62", "r.7(13)", "DLB 23434", "Krishna Murthy") is only for the *second and later* mentions in the same answer — never on its own in a document a reader will file. Never invent a number or date: if a field below is blank, say "number/date not on record here" and offer to fetch.
